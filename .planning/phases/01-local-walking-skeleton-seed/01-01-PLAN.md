# Plan 01-01: Stack Scaffolding & Tracer Path

## Goal
Scaffold the Spring Boot backend and React/Vite frontend projects, configure local PostgreSQL connectivity and CORS, and establish a working end-to-end tracer path between frontend and backend.

## Proposed Tasks

### Task 1: Backend Project Scaffolding
- **Objective**: Scaffold Spring Boot backend application structure under `backend/`.
- **Files**:
  - `backend/pom.xml` or Gradle build file
  - `backend/src/main/java/com/librio/LibrioApplication.java`
  - `backend/src/main/resources/application.yml` (or `application.properties`)
  - `backend/src/main/java/com/librio/config/CorsConfig.java`
- **Details**:
  - Configure Spring Web, Spring Data JPA, PostgreSQL driver, and H2 (for fast local test fallback).
  - Configure CORS allowing `http://localhost:5173` and `http://localhost:3000`.
  - Provide database connection properties reading environment variables with local defaults (`jdbc:postgresql://localhost:5432/librio`, user: `postgres`, password: `postgres`).

### Task 2: Frontend Project Scaffolding
- **Objective**: Scaffold React + Vite SPA frontend structure under `frontend/`.
- **Files**:
  - `frontend/package.json`
  - `frontend/vite.config.js`
  - `frontend/src/App.jsx`
  - `frontend/src/main.jsx`
  - `frontend/src/services/apiClient.js`
- **Details**:
  - Set up Vite with React plugin and `react-router-dom`.
  - Configure API client pointing to backend base URL (`http://localhost:8080`).

### Task 3: End-to-End Tracer Endpoint & Verification
- **Objective**: Implement a minimal ping/tracer controller and frontend status indicator.
- **Files**:
  - `backend/src/main/java/com/librio/controller/HealthController.java`
  - `frontend/src/components/HealthCheck.jsx`
- **Details**:
  - `GET /health` returns `{ "status": "UP", "timestamp": "..." }`.
  - Frontend component fetches `/health` on mount and displays connection status.

## Verification
- Backend build: `mvn clean test` or `./gradlew test` passes.
- Frontend build: `npm run build` or `npm run preview` in `frontend/` succeeds without errors.
- End-to-end tracer: Starting backend on 8080 and frontend on 5173 returns valid status response.
